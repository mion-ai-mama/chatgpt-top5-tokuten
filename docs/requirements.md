- スマホ基準: タイトル30〜36px・セクション見出し23〜27px・STEP見出し21〜24px・本文16〜17px・補足14〜15px・行間1.8

## 3. ページ構成

1. ファーストビュー: 「MION AI GUIDE」・タイトル・初心者向け説明・（必要ならメインビジュアル）
2. 冒頭CTA: 淡いグレージュの横長ボックス。本文より目立たせない
3. この特典でわかること（3〜5項目・チェックマーク）
4. 本編: STEP 01〜（説明→実際の操作画面→手順→初心者向け補足→注意点）。ランキング・比較・事例は内容に合う構成を優先
5. まとめ（3〜5項目＋小さな一歩）
6. 最終CTA: 冒頭より少し存在感を持たせる。強引なセールス表現は使わない

### CTA（ユーザー確認済み 2026-10-16）

- LINE誘導先は従来と同じURL（js/content.js の `lineUrl` 1か所）
- 最終CTAの下に「AIマネタイズの教科書」バナー＋AI収益化サポート会・個別相談の案内を入れる。**教科書の目次画像は使わない**
- LINEで実際に提供される内容と一致する文言のみ。根拠のない期間限定・収入保証・不安をあおる表現・追従バナー・ポップアップは禁止

## 4. UIルール

- 操作画像: 実画面キャプチャのみ（架空画像で代用しない）／角丸8〜12px／細い枠線／十分な余白
- ポイントボックス: 1セクション原則1〜2個
- ボタン: 背景 #786A5E・白文字・角丸12〜24px以上・高さ48px以上
- 人物写真: 提供された本人写真のみ。生成人物を本人として表示しない
  - **写真ありバージョン**: `hero.avatar` に本人アイコンを設定 ／ **なしバージョン**: `hero.avatar: null`（2026-10-16 比較後に決定）

## 5. スマホ・技術

- 基準幅375〜430px。横スクロールなし。PC対応のレスポンシブ
- GitHub Pages静的サイト（HTML/CSS/JS）。セマンティックHTML・alt必須・キーボード操作・WCAG 2.2 AA目標・外部ライブラリ最小限
- 共通CSSで一括変更できる構造。特典ごとのCSS追加は原則しない

## 6. コンテンツ制作ルール

- 文体: やさしく・専門用語は説明・幼すぎない
- ツール仕様は公式情報で確認。無料/有料を明記。未検証は未検証と書く。収益保証をしない
- 操作解説の順: 何ができるか → 準備 → 操作 → 結果 → 注意点。必要ならコピペ用プロンプト（コピーボタン可）
